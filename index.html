moraine

A DuckLake catalog that lives in your bucket. SlateDB-backed, serverless, nothing to operate.
Get startedView on GitHub
ATTACH 'ducklake:moraine:s3://bucket/prefix' AS lake
  (DATA_PATH 's3://bucket/prefix-data/',
   META_DATA_PATH 's3://bucket/prefix-data/', READ_WRITE);

CREATE TABLE lake.events (id BIGINT, payload VARCHAR);
INSERT INTO lake.events VALUES (1, 'hello, bucket');

Nothing to operate

No catalog endpoint to deploy, monitor, or upgrade. A deployment is a bucket and credentials.

Durability for free

Catalog durability is object-store durability. No backup schedule, no WAL shipping — the only way to lose the catalog is to lose the bucket itself.

The bucket is the whole lake

Copying the bucket copies data and catalog together. Environments, migration, and disaster recovery become object-storage operations.

Scale to zero, embed anywhere

An idle lake costs storage, not a 24/7 instance. The core is a plain Rust library any tokio host can commit against directly.
