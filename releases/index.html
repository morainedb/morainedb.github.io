Releases

The newest release also installs signed through Moraine’s extension repository; see Getting started. The builds below are unsigned: start DuckDB with -unsigned to load one. Release notes come from the changelog.

Signing key

Section titled “Signing key”

Registering the repository prints the fingerprint of the key DuckDB pinned. It should be sha256:3aed55458b5a9fa7e54de927dbe5759c0f1622295220ab8ad78c5dff95a361d7; if it differs, drop the repository and do not install from it.

Compatibility

Section titled “Compatibility”

Choose a build matching your DuckDB version and platform. The store-format column lists the formats each build can open. Older stores need moraine_migrate; newer stores need a newer Moraine build. The last column lists supported DuckLake catalog versions. See Upgrading.
